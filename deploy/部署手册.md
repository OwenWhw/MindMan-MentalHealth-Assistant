## 第一步：把 ECS 系统换成 Alibaba Cloud Linux 3（重要）

⚠️ **换系统会清空系统盘上的数据。** 如果系统盘里有需要保留的文件，先备份再更换。

1. 打开阿里云控制台 → 云服务器 ECS → 实例 → 点进你的实例 **i-bp1ad39hu2gxk1djsl7l**

2. 先**停止实例**：点实例右上角的「停止」按钮，在弹出的确认框里点确定，等状态变成「已停止」。
   （停止是必须的，运行中不能换系统盘。）

3. 实例停止后，依次点：**更多 → 磁盘和镜像 → 更换操作系统**
   （不同版本控制台可能是「更多 → 实例状态」，或直接叫「更换操作系统」，找带"更换"字样的即可）

4. 在"更换操作系统"页面里：

   - **镜像类型**：选「公共镜像」
   - **操作系统**：选 **Alibaba Cloud Linux**，版本选 **Alibaba Cloud Linux 3.2104 LTS 64位**
   - **登录凭证**（这是关键，记好！）：
     - 选「自定义密码」
     - 用户名默认是 `root`（不用改）
     - 密码：设置一个你用记得住的强密码（大小写+数字+符号），**记在记事本里**
   - 勾选"我已阅读并同意"之类，点「确认订单」或「确定更换」

5. 期间可能需要手机短信验证码验证身份，按提示完成。

6. 换好后回到实例列表，点「启动」，等状态变回「运行中」。

> 当前控制台显示的公网 IP 是 **47.96.189.190**；更换后请在 ECS 详情页核对实际 IP。

## 第二步：配置安全组，放行 80 端口

服务器默认只开了 22（远程连接用）等少数端口，**网页用的 80 端口要手动放行**，否则你在浏览器里
永远打不开。

1. 控制台 → 实例详情页 → 上方标签切到 **「网络与安全组」**（或左侧菜单「安全组」）

2. 找到这台实例绑定的安全组，点进去 → **「入方向」** 标签 → 点「手动添加」或「快速添加」

3. 添加一条规则：

   | 字段 | 填什么 |
   |---|---|
   | 授权策略 | 允许 |
   | 协议类型 | 自定义 TCP |
   | 端口范围 | **80/80** |
   | 授权对象 | **0.0.0.0/0**（表示允许任何人访问） |
   | 描述 | 网站访问 |

4. 保存。规则一般是立即生效。

> ⚠️ **不要**把 3306（数据库）、6379（Redis）、8848（Nacos）也开放给所有人，那些是内部
> 服务，暴露到公网会被扫描攻击。只需要放行 **80** 即可。

3. 登录成功后，你会看到一个黑底的命令行窗口，光标前面大概长这样：
   ```
   root@iZbp1ad39hu2gxk1djsl7lZ:~#
   ```
   这就是你的服务器了。后面的命令都在这里输入。

2. 打开 WinSCP，新建一个连接，填写：

   |---|---|
   | 文件协议 | SFTP |
   | 主机名 | `47.96.189.190` |
   | 端口号 | 22 |
   | 用户名 | root |
   | 密码 | 你设置的 root 密码 |

3. 点「登录」，第一次连接会弹"是否信任该主机"，点「是」/「接受」。

4. 左边是你电脑的文件，右边是服务器的文件。把部署包 **MindMan-deploy.tar.gz**
   从左边拖到右边的 `/root/` 目录下，等上传完成（几十 MB，看你家网速）。

### 方式 B：用命令行 scp 上传

在**你自己电脑**的 PowerShell（Windows 自带）里执行：

```powershell
scp "C:\Users\魏浩文\Documents\心理健康助手\MindMan-deploy.tar.gz" root@47.96.189.190:/root/
```

输入 root 密码后开始上传。

### 上传完之后，在服务器上解压

回到第三步那个服务器命令行窗口，逐条输入：

```bash

```

最后一条 `ls` 应该能看到 `docker-compose.yml`、`code`、`deploy` 等文件，说明解压成功。

## 第五步：一键部署

在服务器命令行里，执行这一条命令（就在 `MindMan` 目录下）：

```bash
sudo bash deploy/deploy.sh
```

接下来脚本会自动完成：

1. 检查系统、安装 **Docker**（用国内镜像源加速）
2. 配置 Docker 镜像加速和日志清理
3. 内存不足时自动加 swap
4. **自动生成随机密码和密钥**写入 `.env`（不用你手动填）
5. 构建镜像并启动 5 个服务
6. 健康检查并打印访问地址

⏳ **第一次构建会比较慢，大约 5-15 分钟**，因为要下载镜像、编译 Java 后端、打包 Vue 前端。
屏幕上会刷出很多日志，**这是正常的**，不要以为卡死了，耐心等它跑完。

当你看到这样的字样时，就成功了：

```

 ✅ 部署完成！
============================================================
```

## 常见问题排查

**Q1：浏览器一直转圈 / 打不开？**
- 先确认第二步的**安全组 80 端口**是不是真的放行了（最常见原因）
- 再到服务器上执行 `cd /root/MindMan && docker compose ps`，看服务是不是都在 running

**Q2：`docker compose ps` 里 backend 一直重启（Restarting）？**
- 多半是 MySQL 还没就绪后端就去连库了，属正常现象，等 1-2 分钟通常会自己好
- 还不行就看日志：`cd /root/MindMan && docker compose logs --tail=100 backend`

**Q3：构建时提示内存不足 / 被 killed？**
- 你的机器是 4G 内存，脚本已经会自动加 swap 兜底。如果还是失败，执行
  `free -h` 看下 swap 是否生效，或告诉我具体报错。

**Q4：磁盘满了 / 提示 No space left on device？**
- 你的系统盘 40G，Windows 换 Alibaba Cloud Linux 后空间会宽松不少。如果构建多次后满了，执行
  `docker system prune -a` 清理无用镜像（注意这条会删除所有未使用的镜像，下次构建要重下）。

**Q5：怎么改配置（比如填 AI 的 API Key）？**
- 在服务器上编辑 `/root/MindMan/.env`，改完执行 `cd /root/MindMan && docker compose up -d`
- 想启用真实大模型：把 `.env` 里的 `AI_BAILIAN_API_KEY=` 后面填上你的阿里云百炼 Key
  （在 bailian.console.aliyun.com 申请），然后重启

**Q6：怎么看某个服务的日志？**
```bash
cd /root/MindMan
docker compose logs -f backend      # 后端（最常看）
docker compose logs -f frontend     # 前端
docker compose logs -f mysql        # 数据库
```
按 `Ctrl + C` 退出日志查看。

## 以后更新代码怎么办

1. 在电脑上改完代码，重新打包上传（覆盖即可，`.env` 和数据库数据不会丢）
2. 在服务器上执行：
```bash
cd /root/MindMan
sudo bash deploy/update.sh
```

数据库、Redis 的数据都存在 Docker 卷里，**更新代码不会丢数据**。

## 命令速查（存在服务器上备用）

```bash
cd /root/MindMan                # 进入项目目录

docker compose ps               # 查看所有服务状态
docker compose logs -f backend  # 实时看后端日志
docker compose restart backend  # 重启后端
docker compose down             # 停止所有服务（保留数据）
docker compose up -d            # 启动所有服务
docker compose up -d --build    # 重新构建并启动（改了代码后用）

free -h                         # 看内存
df -h                           # 看磁盘
docker system df                # 看 Docker 占用空间
```
