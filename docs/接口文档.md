## 一、通用说明

### 1.1 基础地址

```text
管理端：http://localhost:8080/api
用户端：http://localhost:8080/api/user
```

### 1.2 通用响应格式

所有接口统一返回以下结构：

```json
{
  "code": 200,
  "msg": "操作成功",
  "data": {}
}
```

| 字段 | 类型 | 说明 |
| ---- | ---- | ---- |
| code | int | 业务状态码，200 表示成功 |
| msg | string | 提示信息 |
| data | object/array | 业务数据，无数据时为 `null` |

### 1.3 状态码约定

| code | 说明 |
| ---- | ---- |
| 200 | 操作成功 |
| 400 | 参数错误 |
| 401 | 未登录或 token 已过期 |
| 403 | 无操作权限 |
| 404 | 资源不存在 |
| 500 | 服务器内部错误 |

### 1.4 鉴权方式

除登录、退出登录外，所有管理端接口都需要在 **Header** 中携带 `token`：

```text
token: eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...
```

### 1.5 常用枚举

**文章状态**

| 值 | 文本 |
| -- | ---- |
| 1 | 已发布 |
| 0 | 已下线 |

**分类状态**

| 值 | 文本 |
| -- | ---- |
| 1 | 启用 |
| 0 | 停用 |

**咨询会话状态**

| 值 | 文本 |
| -- | ---- |
| 1 | 进行中 |
| 2 | 已结束 |

### 2.1 登录接口

- **方法**：POST
- **路径**：`/auth/login`
- **鉴权**：无需 token

**请求参数（Body，JSON）**

| 字段 | 类型 | 必填 | 说明 |
| ---- | ---- | ---- | ---- |
| username | string | 是 | 管理员账号 |
| password | string | 是 | 密码 |

**请求示例**

```json
{
  "username": "admin",
  "password": "123456"
}
```

**返回示例**

```json
{
  "code": 200,
  "msg": "操作成功",
  "data": {
    "token": "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...",

      "username": "admin",

  }
}
```

## 四、附录

### 4.1 时间格式

统一使用 `yyyy-MM-dd HH:mm:ss`。

### 4.2 分页参数

分页接口统一使用 `page`（页码，从 1 开始）与 `pageSize`（每页条数），返回结构统一为 `{ total, page, pageSize, list }`。
