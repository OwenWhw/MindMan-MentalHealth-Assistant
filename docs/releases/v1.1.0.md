# MindMan v1.1.0 · 慢慢了解自己

这次更新把倾听、记录和阅读连接起来，并统一了页面的视觉风格。

## 你可以体验什么

- **倾听空间**：与 AI 对话，查看情绪线索和分析依据；保存、归档、恢复会话，生成本次对话总结。
- **情绪花园**：用一朵花留下每天的心情，回看或编辑记录；请 AI 分析当前记录，获得有文字依据的参考评分。
- **记录回顾**：主动带入近 30 天、最多 14 条花园记录，让 AI 整理心情变化与情境联系。
- **心理阅读**：搜索和分类浏览文章，查看来源；自动带上文章标题进入对话，提炼要点或翻译当前收录的英文内容。
- **放松片刻**：选择环境声音或噪声，给自己留一段安静的时间。
- **统一界面**：更新首页、登录、花园、对话和阅读页面的字体、插画、图标与排版。

## 使用方式

查看 [用户指南](../user-guide.md) 或 [安装与部署说明](../developer-guide.md)。支持云端模型与本地 Ollama；可选 Python Agent 用于当前花园记录的回看。

本版本还提供 [Render 免费页面预览配置](../../deploy/render-preview.md)。预览模式没有连接真实模型或云端数据库，不等于完整部署。

## 阅读前请了解

AI 参考评分不是临床测量。证据不足的项目可以不评分；自己的评分与 AI 估计应分别理解。

外部文章可能只收录摘要，翻译和分析以实际收录的内容为范围；全文请通过原文链接阅读。

AI 功能需要可连接的模型服务，不承诺全天在线。使用个人电脑运行模型时，电脑关机或休眠会影响相关功能。
